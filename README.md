# BookishHub

# Adresa repository-ului:
https://github.com/OanaSpatacean/BookishHub

# Pașii de compilare ai aplicației, pașii de instalare și lansare a aplicației:
```bash
git clone https://github.com/OanaSpatacean/BookishHub
cd ./BookishHub/bookishhub/
npm install
npm run dev
```

Aplicația este disponibilă la: http://localhost:3000  
Adresa corespunzătoare este printată în terminal.
Aceasta trebuie inserată în browser-ul favorit.
